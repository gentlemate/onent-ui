## Structure

```html
<oui-toaster>
    <oui-toast>
        <oui-toast-title></oui-toast-title>
        <oui-toast-description></oui-toast-description>
        <oui-toast-action></oui-toast-action>
    </oui-toast>
</oui-toaster>
```

Toasts written in a toaster open with `show()` or `open` and stay in the page once closed. Elements with `data-close` close the toast on click.

`toast()` builds this markup in the first `oui-toaster` of the page (or the first one with its `placement` option) and removes it once the toast is closed. It creates the toaster when the page has none, but place one in the page anyway: screen readers only announce a message reliably when its toaster was already there.

### Actions

`actions` adds buttons under the message, from one action or an array. Each one closes the toast on click. In markup, put them in `oui-toast-action` with `data-close`.

<Preview
    syncKey="toast"
    tabs={{
        Imperative: `<oui-button onclick="toast({ title: 'Invitation received', duration: 0, actions: [{ label: 'Accept', onClick: () => toast('Invitation accepted') }, { label: 'Decline', variant: 'outline', onClick: () => toast('Invitation declined') }] })">Invite</oui-button>`,
        Declarative: `<oui-toaster>
    <oui-toast id="invitation" duration="0">
        <oui-toast-title>Invitation received</oui-toast-title>
        <oui-toast-action>
            <oui-button data-close>Accept</oui-button>
            <oui-button variant="outline" data-close>Decline</oui-button>
        </oui-toast-action>
    </oui-toast>
</oui-toaster>
<oui-button onclick="document.querySelector('#invitation').show()">Invite</oui-button>`,
    }}

## toast()

`toast()` takes a title or an object, and returns the `oui-toast`: `hide()` closes it early.

| Option                                                                                     | Type                                               | Description                                                                                                                                                    |
| ------------------------------------------------------------------------------------------ | -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`                                                                                    | `string`                                           | The toast title                                                                                                                                                |
| `description`                                                                              | `string`                                           | The toast message                                                                                                                                              |
| `actions`                                                                                  | `OuiToastActionOptions \| OuiToastActionOptions[]` | Buttons under the message that close the toast on click. Each action is `{ label: string; variant?: OuiButtonVariant; onClick?: (event: MouseEvent) => void }` |
| `toaster`                                                                                  | `OuiToaster`                                       | The toaster to show the toast in. Defaults to the first `oui-toaster` of the page, created if needed                                                           |
| `placement`                                                                                | `OuiToasterPlacement`                              | Shows the toast in the first `oui-toaster` with this placement, created if there is none. Ignored with `toaster`                                               |
| `tone`, `variant`, `icon`, `withoutIcon`, `withoutClose`, `duration`, `closeLabel`, `live` |                                                    | The [`oui-toast` properties](#oui-toast)                                                                                                                       |

## Behavior

- Toasts never take the focus. The toaster is a landmark region named by `label`, so keyboard and screen reader users can reach it.
- Screen readers read each toast aloud when it opens. `warning` and `danger` toasts interrupt the current speech (`live="assertive"`), the other tones wait for it to finish (`live="polite"`). Set `live` to change it, or to `off` to stay silent.
- The timer pauses while the pointer or the focus is on the toasts, and while the page is hidden. Escape closes the focused toast.
- When more than `max` toasts are open (3 by default), the oldest one closes.
- A toast can close before the user reaches it: give a toast with an action `duration: 0`, or make the action available elsewhere too.
- A toast opened while an `oui-modal` is open stays behind the modal.

## API

### oui-toaster

#### Properties

| Property    | Attribute   | Type                                                                                            | Default           | Description                                                                                      |
| ----------- | ----------- | ----------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------ |
| `placement` | `placement` | `"top-start" \| "top-center" \| "top-end" \| "bottom-start" \| "bottom-center" \| "bottom-end"` | `"bottom-end"`    | Corner or edge of the screen where the toasts stack. The newest toast is the closest to the edge |
| `max`       | `max`       | `number`                                                                                        | `3`               | Maximum number of open toasts: opening one more closes the oldest. `0` removes the limit         |
| `label`     | `label`     | `string`                                                                                        | `"Notifications"` | Accessible name of the region holding the toasts                                                 |

#### Slots

| Name      | Description              |
| --------- | ------------------------ |
| (default) | The `oui-toast` elements |

#### CSS custom properties

| Name                  | Default | Description                           |
| --------------------- | ------- | ------------------------------------- |
| `--oui-width-toaster` | `22rem` | Width of the toasts                   |
| `--oui-inset-toaster` | `1rem`  | Distance from the edges of the screen |

#### CSS parts

| Name   | Description                   |
| ------ | ----------------------------- |
| `base` | The region holding the toasts |

### oui-toast

#### Properties

| Property       | Attribute       | Type                                                        | Default     | Description                                                                                                                                                 |
| -------------- | --------------- | ----------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tone`         | `tone`          | `"default" \| "info" \| "success" \| "warning" \| "danger"` | `"default"` | Meaning of the message: sets the color, the default icon and how it is announced. `default` uses the text color                                             |
| `variant`      | `variant`       | `"default" \| "secondary" \| "outline"`                     | `"default"` | Visual style                                                                                                                                                |
| `icon`         | —               | `IconNode`                                                  | —           | Lucide icon, set as a JS property. Defaults to an icon matching the tone                                                                                    |
| `withoutIcon`  | `without-icon`  | `boolean`                                                   | `false`     | Hides the icon                                                                                                                                              |
| `withoutClose` | `without-close` | `boolean`                                                   | `false`     | Hides the close button                                                                                                                                      |
| `duration`     | `duration`      | `number`                                                    | `5000`      | Time in milliseconds before the toast closes by itself. `0` keeps it open until it is closed                                                                |
| `closeLabel`   | `close-label`   | `string`                                                    | `"Close"`   | Accessible name of the close button                                                                                                                         |
| `live`         | `live`          | `"off" \| "polite" \| "assertive"`                          | —           | How screen readers announce the toast when it opens: `assertive`, `polite` or `off`. Defaults to `assertive` for `warning` and `danger`, `polite` otherwise |
| `open`         | `open`          | `boolean`                                                   | `false`     | Whether it is open. Setting it directly skips `oui-show` / `oui-hide`                                                                                       |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                                                                   |
| ---------------- | --------------------------------------------------------------------------------------------- |
| `oui-show`       | The toast is about to open. Cancelable                                                        |
| `oui-after-show` | The toast is open and its enter animation finished                                            |
| `oui-hide`       | The toast is about to close (close button, `data-close`, Escape, timer, `hide()`). Cancelable |
| `oui-after-hide` | The toast is hidden and its exit animation finished                                           |

#### Slots

| Name      | Description                                                                                                                               |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| (default) | The toast content: `oui-toast-title`, `oui-toast-description` and `oui-toast-action`. Elements with `data-close` close the toast on click |
| `icon`    | A custom icon, replacing the `icon` property                                                                                              |

#### CSS custom properties

| Name                       | Default                   | Description                       |
| -------------------------- | ------------------------- | --------------------------------- |
| `--oui-spacing-toast`      | `1rem`                    | Padding                           |
| `--oui-radius-toast`       | `var(--oui-radius-panel)` | Border radius                     |
| `--oui-radius-toast-close` | `var(--oui-radius-pill)`  | Border radius of the close button |

#### CSS parts

| Name           | Description                                                  |
| -------------- | ------------------------------------------------------------ |
| `base`         | The toast container                                          |
| `icon`         | The `oui-icon` rendered from the tone or the `icon` property |
| `close-button` | The close button (not rendered with `without-close`)         |
