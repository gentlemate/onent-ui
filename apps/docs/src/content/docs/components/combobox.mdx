## Import

```js
import "onent-ui/combobox";
import "onent-ui/form-field";
```

The label, the description, the hint and the error come from [`oui-form-field`](../form-field/).

## Structure

```html
<oui-combobox>
    <oui-combobox-group>
        <oui-combobox-option></oui-combobox-option>
    </oui-combobox-group>

    <oui-combobox-option></oui-combobox-option>

    <oui-combobox-separator></oui-combobox-separator>
</oui-combobox>
```

### Custom filtering

`ignore-filter` shows every option whatever the query. Listen to `oui-search` and replace the options yourself, for example with the results of a request.

```js
combobox.addEventListener("oui-search", async () => {
    const users = await searchUsers(combobox.query);
    combobox.replaceChildren(
        ...users.map((user) => {
            const option = document.createElement("oui-combobox-option");
            option.value = user.id;
            option.textContent = user.name;
            return option;
        }),
    );
});
```

## Keyboard

The focus stays in the input. Typing opens the listbox and filters the options. <kbd>↑</kbd> / <kbd>↓</kbd> open the listbox and move the highlight, <kbd>Enter</kbd> selects the highlighted option, <kbd>Escape</kbd> closes the listbox and restores the text. With `multiple`, <kbd>Backspace</kbd> in an empty input removes the last tag.

Leaving the field with an empty text clears the selection. Otherwise the text goes back to the selected option, unless `allow-custom-value` is set.

## API

### oui-combobox

#### Properties

| Property           | Attribute            | Type                                                                                                                                                                 | Default          | Description                                                                          |
| ------------------ | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------ |
| `name`             | `name`               | `string`                                                                                                                                                             | `""`             | Name submitted with the form                                                         |
| `value`            | `value`              | `string \| string[]`                                                                                                                                                 | `""`             | Value of the selected option, or the array of selected values when `multiple` is set |
| `query`            | `query`              | `string`                                                                                                                                                             | `""`             | Text typed to filter the options                                                     |
| `placeholder`      | `placeholder`        | `string`                                                                                                                                                             | `""`             | Text shown when nothing is selected or typed                                         |
| `placement`        | `placement`          | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the listbox relative to the field                                        |
| `distance`         | `distance`           | `number`                                                                                                                                                             | `4`              | Gap in pixels between the field and the listbox                                      |
| `multiple`         | `multiple`           | `boolean`                                                                                                                                                            | `false`          | Allows selecting several options, shown as tags in the field                         |
| `ignoreFilter`     | `ignore-filter`      | `boolean`                                                                                                                                                            | `false`          | Shows every option whatever the query, to filter them yourself                       |
| `allowCustomValue` | `allow-custom-value` | `boolean`                                                                                                                                                            | `false`          | Accepts the typed text as a value, even if no option matches it                      |
| `openOnFocus`      | `open-on-focus`      | `boolean`                                                                                                                                                            | `false`          | Opens the listbox when the field gets the focus                                      |
| `emptyText`        | `empty-text`         | `string`                                                                                                                                                             | `"No results."`  | Message shown when no option matches the query, unless the `empty` slot is filled    |
| `disabled`         | `disabled`           | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                                            |
| `required`         | `required`           | `boolean`                                                                                                                                                            | `false`          | Marks the field as required for form validation                                      |
| `invalid`          | `invalid`            | `boolean`                                                                                                                                                            | `false`          | Marks the field as invalid without displaying a message                              |
| `ariaLabel`        | `aria-label`         | `string \| null`                                                                                                                                                     | `null`           | Accessible name of the field, set with the `aria-label` attribute                    |
| `focusTarget`      | —                    | `HTMLInputElement`                                                                                                                                                   | —                | The inner element that receives the focus (read-only)                                |
| `open`             | `open`               | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `oui-show` / `oui-hide`                |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                           |
| ---------------- | ----------------------------------------------------- |
| `input`          | The user changed the selection                        |
| `change`         | The user changed the selection                        |
| `oui-search`     | The user changed the query                            |
| `oui-show`       | The listbox is about to open. Cancelable              |
| `oui-after-show` | The listbox is open and its enter animation finished  |
| `oui-hide`       | The listbox is about to close. Cancelable             |
| `oui-after-hide` | The listbox is closed and its exit animation finished |

#### Slots

| Name      | Description                                                                           |
| --------- | ------------------------------------------------------------------------------------- |
| (default) | The `oui-combobox-option`, `oui-combobox-group` and `oui-combobox-separator` elements |
| `empty`   | Content shown when no option matches the query, in place of `emptyText`               |

#### CSS custom properties

| Name                     | Default                    | Description                     |
| ------------------------ | -------------------------- | ------------------------------- |
| `--oui-height-combobox`  | `var(--oui-height-field)`  | Minimum height of the field     |
| `--oui-spacing-combobox` | `var(--oui-spacing-field)` | Horizontal padding of the field |
| `--oui-radius-combobox`  | `var(--oui-radius-field)`  | Border radius of the field      |

#### CSS parts

| Name         | Description                                                 |
| ------------ | ----------------------------------------------------------- |
| `field`      | The box holding the tags, the input and the chevron         |
| `control`    | The inner `<input>` element                                 |
| `tag`        | The `oui-badge` of a selected value, when `multiple` is set |
| `tag-remove` | The button removing a tag                                   |
| `chevron`    | The button toggling the listbox                             |
| `popup`      | The listbox panel                                           |
| `empty`      | The wrapper of the `empty` slot                             |
