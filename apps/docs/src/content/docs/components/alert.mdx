
`icon` sets another Lucide icon, the `icon` slot takes any element and `without-icon` hides it.

### Dismissible

`dismissible` renders a close button. Elements with `data-close` close the alert too, `hide()` closes it from code and `show()` or `open` brings it back.

## Behavior

- The alert gets `role="alert"` for `warning` and `danger`, and `role="status"` for the other tones: screen readers announce it when it is added to the page or shown again. Use `live` to change it.
- Each tone has its own icon, so the meaning does not rely on color only. With `without-icon`, say it in the title.
- When the alert closes while it holds the focus, the focus moves to the next focusable element.

## API

### oui-alert

#### Properties

| Property      | Attribute      | Type                                                        | Default     | Description                                                                                                                                                                                      |
| ------------- | -------------- | ----------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `tone`        | `tone`         | `"default" \| "info" \| "success" \| "warning" \| "danger"` | `"default"` | Meaning of the message: sets the color, the default icon and how it is announced. `default` uses the text color                                                                                  |
| `variant`     | `variant`      | `"default" \| "secondary" \| "outline" \| "ghost"`          | `"default"` | Visual style                                                                                                                                                                                     |
| `icon`        | —              | `IconNode`                                                  | —           | Lucide icon, set as a JS property. Defaults to an icon matching the tone                                                                                                                         |
| `withoutIcon` | `without-icon` | `boolean`                                                   | `false`     | Hides the icon                                                                                                                                                                                   |
| `dismissible` | `dismissible`  | `boolean`                                                   | `false`     | Renders a close button                                                                                                                                                                           |
| `open`        | `open`         | `boolean`                                                   | `true`      | Whether the alert is shown. Setting it directly skips `oui-hide`                                                                                                                                 |
| `closeLabel`  | `close-label`  | `string`                                                    | `"Close"`   | Accessible name of the close button                                                                                                                                                              |
| `live`        | `live`         | `"off" \| "polite" \| "assertive"`                          | —           | How screen readers announce the alert when it appears: `assertive` (`role="alert"`), `polite` (`role="status"`) or `off`. Defaults to `assertive` for `warning` and `danger`, `polite` otherwise |

#### Methods

| Name     | Description                         |
| -------- | ----------------------------------- |
| `hide()` | Closes the alert (fires `oui-hide`) |
| `show()` | Shows the alert again               |

#### Events

| Name             | Description                                                                    |
| ---------------- | ------------------------------------------------------------------------------ |
| `oui-hide`       | The alert is about to close (close button, `data-close`, `hide()`). Cancelable |
| `oui-after-hide` | The alert is hidden and its exit animation finished                            |

#### Slots

| Name      | Description                                                                                                                               |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| (default) | The alert content: `oui-alert-title`, `oui-alert-description` and `oui-alert-action`. Elements with `data-close` close the alert on click |
| `icon`    | A custom icon, replacing the `icon` property                                                                                              |

#### CSS custom properties

| Name                       | Default                   | Description                       |
| -------------------------- | ------------------------- | --------------------------------- |
| `--oui-spacing-alert`      | `1rem`                    | Padding                           |
| `--oui-radius-alert`       | `var(--oui-radius-panel)` | Border radius                     |
| `--oui-radius-alert-close` | `var(--oui-radius-pill)`  | Border radius of the close button |

#### CSS parts

| Name           | Description                                                  |
| -------------- | ------------------------------------------------------------ |
| `base`         | The alert container                                          |
| `icon`         | The `oui-icon` rendered from the tone or the `icon` property |
| `close-button` | The close button (rendered with `dismissible`)               |

### oui-alert-title

#### Slots

| Name      | Description     |
| --------- | --------------- |
| (default) | The alert title |

### oui-alert-description

#### Slots

| Name      | Description                             |
| --------- | --------------------------------------- |
| (default) | The alert message (text, links, lists…) |

### oui-alert-action

#### Slots

| Name      | Description                                                                             |
| --------- | --------------------------------------------------------------------------------------- |
| (default) | Buttons or links under the message. Elements with `data-close` close the alert on click |
